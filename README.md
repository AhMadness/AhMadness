## Featured Work

### [Atlas DMS](https://github.com/AhMadness/atlas-dms)

An English/Arabic on-prem document management platform with structured

reporting, Windows deployment, backup and restore, and mobile access. The
public repository is a product overview; the source remains private.

### [pyAHK](https://github.com/AhMadness/pyAHK)

A PyQt6 desktop automation builder that converts visual hotkey, keyboard,
mouse, text, and delay sequences into validated AutoHotkey v2 scripts.

### [pyWerewolf](https://github.com/AhMadness/pyWerewolf)

A FastAPI and WebSocket multiplayer game with QR-based phone joining,

host authorization, persistence, and browser tests. The public repository is a
sanitized project overview.

### [Imposter](https://github.com/AhMadness/Imposter)

An open-source PyQt6 party game with English and Arabic interfaces, private

content, and a companion category and word-pack manager.

### [Pokemon Type Matchup Studio](https://github.com/AhMadness/pyPokemon)

An open-source Python desktop application for exploring modern offensive and
